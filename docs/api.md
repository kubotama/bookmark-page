## キーワード

### 全キーワードの取得: GET /keywords

すべてのキーワードのデータを返します。

| 項目             | 値                                                           |
| ---------------- | ------------------------------------------------------------ |
| メソッド         | GET                                                          |
| URL              | /keywords                                                    |
| リクエストボディ | なし                                                         |
| レスポンス (200) | { success: true, data: Array<{ id: string, name: string }> } |
| レスポンス (500) | データベースエラー                                           |
